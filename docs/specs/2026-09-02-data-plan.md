# OSRT-Ostinato data plan — pretraining, anneal, SFT, RL (2026-09-02)

**Target.** An all-round reasoning model with a slight propensity to code (and
therefore maths), comfortable with highly technical language, across a range
of programming languages. 968M physical / 263M active, 5.31B pretraining
tokens, then SFT and GRPO on HRA adapters over a frozen base (roadmap §18.1).

**Method.** Two verified surveys on 2026-09-02: every NVIDIA `nvidia/*` dataset
(org listing + raw cards + tech reports for Nano 2, Nemotron 3 Nano/Super) and
the non-NVIDIA landscape (FineWeb/DCLM/Dolma 3, Stack v2/v3/Stack-Edu,
SmolLM2/3 and OLMo 3 recipes, SFT and RLVR pools, small-model reports). Every
HF id below resolved on that date. Seeds from `CodeHalwell/llm-datasets`.

---

## 0. The four findings that shape the plan

1. **Long teacher traces hurt at this scale.** The Small Model Learnability
   Gap ([2502.12143](https://arxiv.org/abs/2502.12143)) measured 1.5B students
   losing 7.1 points on long CoT (avg 3,385 tok) vs short (576 tok); a **1:4
   long:short mix** (avg 1,249 tok) recovers it. Falcon-H1-Tiny (90M–600M):
   "CoT traces cause repetition loops rather than improved reasoning" — traces
   removed below 1B. Phi-4-mini-reasoning (3.8B): direct SFT on LIMO/s1K
   degrades. OpenThoughts3-1.2M has 62% of traces truncated at 16K — never
   raw. → SFT is **no-think backbone + ≤4K-token verified short-think slice**,
   and the pretraining anneal carries *no* long traces.
2. **Only a few RL pools carry a difficulty signal calibrated to ≤1.5B
   models.** SimpleRL-Zoo level configs, Skywork-OR1 `model_difficulty`
   (1.5B column), SynLogic-easy, Countdown, LeetCode-Easy, Dolci `passrate`,
   Nemotron-RL-knowledge-mcqa `reward_profiles`. DAPO-17k and DeepMath-103K
   are out of reach. Everything NuminaMath/DeepScaleR-derived must be
   decontaminated against MATH-500/AIME before use (DeepMath measured 76.6%
   MATH-500 overlap in that raw pool).
3. **Multi-language code needs Stack v3.** Stack-Edu (125B, 15 langs) is
   SWHIDs-only (a 6-hour S3 fetch) and Rust/Go are <2B each. The 2026
   [HuggingFaceCode/stack-v3-train](https://huggingface.co/datasets/HuggingFaceCode/stack-v3-train)
   is **inline, ODC-By, ungated**, ~3.6T tokens with a `language` field —
   the practical source for JS/TS, Rust, Go, Java, SQL, Shell. It has no
   decontamination statement and post-dates LiveCodeBench.
4. **NVIDIA's own curriculum for its smallest models.** Nemotron 3 Nano
   (3B active, 25T): Phase 1 (94%) web 51 / code 17 / math 6 / STEM-SFT 11;
   Phase 2 (6%) code 21 / math 12.5 / STEM-SFT 22 / code-SFT 7 / web 36.
   Nano 2 Phase 3: STEM-SFT 32%. SmolLM3 decay: 63 web / 24 code / 13 math.
   OLMo 3 Dolmino: web 27 / code 20 / math 19 / QA 14 / thinking 8 / instr 6.
   → the last 15% goes heavy on instruction-shaped synthetic text and code.

## 3. RL — GRPO with verifiable rewards

**Recipe carried from v6** (memory: `project_grpo_prelaunch`,
`project_grpo_wave1_reward_defect`): rollout temperature 0.4, strict answer
extraction, dead-prompt filtering (62–73% of prompts were dead at v6's
level), **no proximity partial credit** (it paid wrong answers 70% of a
correct one and made the model worse), noise floor ~0.5pp on GSM8K.
**New from Nemotron 3 Nano:** drop prompts with 100% pass rate, then a
pass-rate curriculum easy→hard; all environments trained simultaneously.

## 4. Contamination policy

Evaluation suite assumed: GSM8K, MATH-500, HumanEval/MBPP+, LiveCodeBench,
MMLU, IFEval, GPQA. Rules:

- **Prefer sets with a published decontamination statement**: CC-Math-v1,
  FineMath, OpenMathInstruct-2, OpenMathReasoning, OpenCodeInstruct,
  OpenCodeReasoning, AceReason-*, Llama-Nemotron-PT, Math-v2/SFT-Math-v3/v4
  (StackExchange slice), Cascade-RL-Math.
- **Run our own 13-gram pass** (FineMath's method) over every anneal, SFT
  and RL source against the suite above. Non-negotiable for Stack v3 (no
  statement, post-dates LCB), Skywork-OR1, SimpleRL-Zoo, Nemotron-CC-v2,
  Nemotron-Pretraining-Code-v2, Specialized-v1.
- **Do not use** `nvidia/Nemotron-Pretraining-Specialized-v1.1` MCQ (seeded
  from MMLU auxiliary_train) while MMLU is an eval; `Nemotron-Science-v1`
  and `OpenScience` are GPQA-*style* generations — keep only if GPQA is not
  reported, or accept the caveat in the paper.
- **Training on GSM8K/MATH *train* is fine**; the hazard is *test* leakage
  through NuminaMath/DeepScaleR-derived pools.

## 6. What has to change in the code

1. **`data.py`: a per-dataset row filter.** Stack v3 needs
   `language ∈ set` with per-language sampling weights (§1.4); the
   short-think slice needs a token-length filter; several sets need a
   `verified == True` / `average_test_score == 1.0` filter. One
   `filter: Callable[[row], bool]` + `subsample: dict[str, float]` per
   dataset entry covers all three.
2. **`train_config.py`: the phase tables in §1** replace today's. Weights
   sum to 1.0 per phase; the validator should assert it.
3. **A decontamination script** (`scripts/decontam_ngram.py`): 13-gram
   overlap of a streamed sample against the eval suite, reporting hit rate
   per source. Run before the trunk on every §1.3, §2, §3 source.
4. **SFT and GRPO configs** ported from `archive/v6` into
   `src/osrt/train_config.py` as `SFTConfig` / `GRPOConfig`, with the

## 7. Sources not adopted, and why (so nobody re-litigates them)

- **Nemotron-CC v1 / v2.1 raw crawl**: at 5B tokens we never exhaust
  FineWeb-Edu + HQ-Synthetic; v1 is explicitly not decontaminated and has no
  HF mirror.
- **Nemotron-Pretraining-Code-v1/v2/v3 Code-Metadata**: metadata only; needs
  a GitHub re-fetch. Stack v3 is inline.
- **Stack-Edu**: SWHIDs only; ~6 h fetch; Rust/Go thin. Stack v3 covers it.
- **DCLM-baseline**: card says research use; weaker code/math; FineWeb-Edu
  is the same idea with a cleaner licence.
- **smoltalk2 `Mid`** (35B reasoning mid-train, 53% NVIDIA): built for a 3B
  after 140B of reasoning mid-training; traces average ~14.5K tokens.
- **Nemotron-Post-Training-Dataset-v1/v2**: long R1-0528 traces, no
  decontamination statement; superseded by the v3/v4 SFT sets used above.
- **Nemotron-Cascade-2-SFT-Data**: NVIDIA Open Model License rather than
  CC-BY; 24.8M rows mostly chat; nothing in it we lack.
- **OpenThoughts3-1.2M**: 62% truncated traces; QwQ-32B teacher; 7B-scale
  evidence only.
- **Agentic / SWE trajectory sets** (Nemotron-SWE, SWE-smith, AgentTrove,
  OpenThoughts-Agent): 8–64K-token trajectories; a 263M-active model cannot
  absorb them and 8192 context cannot hold them.
